# Bridge of Allan Judo Grading Trainer

A free study aid for JudoScotland kyu gradings (red to brown) and junior mon gradings (1st to 18th Mon): Japanese words with audio, grading checklists, mock grading, match tests, theory questions and contest rules.

Made for Bridge of Allan Judo Club. Open to anyone. Unofficial: always check with your coach.

Open it at the GitHub Pages address for this repository. On a phone, use "Add to Home Screen" to install it and use it offline.
